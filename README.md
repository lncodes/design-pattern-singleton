# Singleton Design Pattern

Hub repository for the **Singleton** design pattern. Language implementations are included as Git submodules:

| Folder | Implementation |
|---|---|
| `csharp/` | [design-pattern-singleton-csharp](https://github.com/lncodes/design-pattern-singleton-csharp) — C# implementation with tests and docs |

## Clone with submodules

```bash
git clone --recurse-submodules https://github.com/lncodes/design-pattern-singleton.git
```

Already cloned? Run `git submodule update --init --recursive`.
